# Plannr

A tiny weekly planner. Static pages, no build step.

- `npm start` serves the site on http://localhost:4173
- `npm test` runs the unit tests (Node 20+, no dependencies)

## Dark mode

Use the **Dark mode** checkbox on the Settings page to switch themes. The choice is saved in browser `localStorage` under `plannr-theme` and applied across all pages on your next visit.
