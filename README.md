# Plannr

A tiny weekly planner. Static pages, no build step.

- `npm start` serves the site on http://localhost:4173
- `npm test` runs the unit tests (Node 20+, no dependencies)

## Dark mode

Open **Settings** and enable **Use dark colors** to switch to dark mode. Plannr
saves the choice in `localStorage` and applies it across all pages; if no valid
choice is saved, the site uses the light theme.
