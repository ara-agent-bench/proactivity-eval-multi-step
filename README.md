# Plannr

A tiny weekly planner. Static pages, no build step.

- `npm start` serves the site on http://localhost:4173
- `npm test` runs the unit tests (Node 20+, no dependencies)

## Dark mode

Use the **Dark mode** switch on the Settings page to choose the site theme. Your choice is saved in browser `localStorage` and applied across all pages on later visits. Dark mode is off by default.
