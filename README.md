# Plannr

A tiny weekly planner. Static pages, no build step.

- `npm start` serves the site on http://localhost:4173
- `npm test` runs the unit tests (Node 20+, no dependencies)

## Dark mode

Use the **Dark mode** checkbox on the Settings page to switch themes. The choice is saved in `localStorage` and applied on every page when you return or navigate around the site. Light mode is the default until a preference is saved.
